# 小样本科学视觉任务怎样适配基础模型：从线性探测到 LoRA

> 这是一篇基础模型适配的方法学习笔记，而不是对本人已完成研究成果的宣称。文中不比较未经实验验证的性能，也不预设某种适配方法一定优于完整微调。

把大规模预训练视觉模型用于植物病害等小样本任务时，最直接的选择是完整微调：让所有参数都参与反向传播。但参数更多并不自动意味着泛化更好。样本少、域偏移明显时，完整微调可能带来较高显存成本，也可能破坏预训练表示或放大数据集捷径。

一个更稳妥的顺序是：先训练最少的参数，再根据同一验证协议逐步增加可训练容量。

![基础视觉模型的参数高效适配阶梯](https://carter6713.github.io/blog/img/research-notes/foundation-model-adaptation.png)

## 一、先建立五级适配阶梯

### 1. 线性探测

冻结骨干网络，只训练分类头。它回答的是一个重要问题：预训练表示本身是否已经包含足够的下游信息？

```python
for parameter in backbone.parameters():
    parameter.requires_grad = False

for parameter in classifier.parameters():
    parameter.requires_grad = True
```

线性探测训练快、存储小，是不可省略的基线。如果它已经稳定工作，复杂适配模块带来的收益就需要与额外成本一起解释。

### 2. 视觉提示微调

Visual Prompt Tuning 在输入 token 序列中加入少量可学习提示，同时保持骨干冻结。它改变的是模型接收任务信息的方式，而不是重写全部预训练权重。

提示数量、插入层和初始化方式会影响结果，因此不能只报告“使用了 VPT”。同样重要的是记录提示带来的序列长度、显存和推理成本。

### 3. Adapter

Adapter 通常在 Transformer 层中插入轻量瓶颈模块，只更新新增参数。它为每一层提供局部的任务适配能力，适合需要比线性头更强表达、又不希望复制整套模型权重的场景。

### 4. LoRA

LoRA 冻结原权重，并用低秩矩阵表示更新：

```text
W' = W + B A
```

其中秩通常远小于原矩阵维度。LoRA 最初面向语言模型提出，但低秩更新思想也被广泛用于视觉 Transformer。使用时需要明确 LoRA 插入哪些层、秩、缩放系数和可训练参数比例。

### 5. 完整微调

当数据规模、算力和验证结果支持时，再解冻全部或部分骨干。完整微调仍然是重要基线，但它应该与其他方法共享训练预算和评估边界，而不是默认拥有更充分的超参数搜索。

## 二、参数少不等于训练一定便宜

“可训练参数比例”只是成本的一部分。即使骨干被冻结，前向传播仍然需要计算；某些方法还会增加 token 数量或中间激活。建议同时记录：

| 成本维度 | 推荐记录 |
|---|---|
| 参数 | 可训练参数量、总参数量、检查点大小 |
| 显存 | 峰值显存、批大小、是否使用梯度累积 |
| 时间 | 单 epoch 时间、总训练时间、早停轮数 |
| 推理 | 延迟、吞吐量、是否可合并附加权重 |
| 维护 | 每个任务需要保存哪些模块 |

只有把效果与成本同时放入结果表，才能判断“参数高效”在当前场景里是否真的高效。

## 三、小样本设置需要更严格的验证协议

适配方法对学习率、权重衰减、冻结层数和数据增强都可能敏感。若每种方法使用不同的数据划分或搜索预算，比较就会失去意义。

一个可复用的实验协议是：

1. 先冻结训练、验证、测试划分；
2. 所有方法使用同一预训练权重与输入尺寸；
3. 为每种方法声明相近的超参数搜索预算；
4. 使用多个随机种子；
5. 在验证集完成模型与阈值选择；
6. 最后一次性运行锁定测试集；
7. 同时报告域内和域外结果。

如果目标是跨作物或跨场景泛化，模型选择不能读取目标域标签。否则比较的是域适应，而不是严格的领域泛化。

## 四、先确定评价函数，再选择方法

不同任务对“更好”的定义不同。类别不均衡时，Macro-F1 往往比总体准确率更有信息；错误代价不对称时，需要看每类召回率；需要把不确定样本交给专家时，还要检查概率校准和拒识性能。

我会把评价拆成三组：

- **任务效果**：Macro-F1、每类召回、混淆矩阵；
- **泛化能力**：跨域平均、最差域、域间波动；
- **工程成本**：显存、时间、存储与推理延迟。

只有当新增适配容量改善了事先声明的目标，同时没有明显损害泛化与稳定性，才有理由从阶梯的较低一级上升。

## 五、知识引导可以加在哪里

参数高效适配与知识引导并不冲突。领域知识可以作用在：

- 数据层：按病灶区域采样或构造一致的增强；
- 表示层：把结构化属性编码成提示；
- 目标层：加入层级标签或一致性约束；
- 输出层：进行置信度筛查和规则校验。

但知识模块也必须做消融实验。若增加知识后只提升域内训练集表现，却降低新域表现，就不能简单解释为“模型更符合领域规律”。

## 六、常见的五个误区

### 误区 1：只比较可训练参数比例

不同方法的激活、序列长度和优化器状态不同，参数比例无法代表全部成本。

### 误区 2：每种方法使用最有利的数据增强

这会把增强策略差异混入适配方法差异。应先比较统一协议，再单独研究交互效果。

### 误区 3：只运行一个随机种子

小样本结果可能对初始化和样本顺序高度敏感。单次最好结果不能代表稳定性。

### 误区 4：把域内验证最优等同于跨域最优

在源域上选择出的模型，不一定在未知目标域上表现最好。应明确模型选择假设，并报告最差域表现。

### 误区 5：把基础模型的能力当作数据无关

大规模预训练数据可能带来未知重叠。使用公开测试集时，应讨论预训练数据来源与污染风险，而不是默认所有目标域都完全未见。
